# Workout Hacker — Onboarding Feature
# Complete React Native + TypeScript Implementation

## 📁 Folder Structure

```
WorkoutHacker/
├── App.tsx                                    ← Root integration point
└── src/
    ├── theme/
    │   └── colors.ts                          ← Design tokens (colors, spacing, typography)
    ├── navigation/
    │   └── types.ts                           ← Navigation param list types
    └── features/
        └── onboarding/
            ├── index.ts                       ← Barrel export (public API)
            ├── OnboardingNavigator.tsx        ← Splash → Carousel flow controller
            ├── constants/
            │   └── slides.ts                  ← Slide data (single source of truth)
            ├── hooks/
            │   └── useOnboarding.ts           ← All carousel logic (scroll, index, CTA)
            ├── components/
            │   ├── CTAButton.tsx              ← Reusable button (filled / outline / ghost)
            │   ├── PaginationDots.tsx         ← Animated dot indicators
            │   ├── SlideImage.tsx             ← Image with dev placeholder fallback
            │   └── OnboardingSlide.tsx        ← Single slide renderer (title + image + desc)
            └── screens/
                ├── SplashScreen.tsx           ← Screen 1: logo + spinner + tagline
                └── OnboardingScreen.tsx       ← Screens 2-5: horizontal carousel
```
